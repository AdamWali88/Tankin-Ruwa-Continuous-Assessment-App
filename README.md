# Umar Idris Government Secondary School — CA Record V35

This is an offline-capable PWA for Umar Idris Government Secondary School, Unguwar Tankin Ruwa Rigasa Kaduna. Upload all files in this ZIP to the root of the existing GitHub Pages repository.

## Updates in V35
- Clearer, higher-contrast royal blue, indigo, and teal colour combination; the interface colours no longer change based on the school logo.
- Added a dedicated **User Access Management** section in the sidebar for the Administrator.
- Only the Administrator can create and delete teacher accounts. There is no public self-sign-up.
- Existing school app functions retained from V34.
- Fixed score scheme: CA maximum 30 + examination maximum 70 = total 100.
- CSV score export/template, Print / Save PDF, students, classes, assessments, question bank, final examination, backup/restore, and dashboard navigation retained.
- Service-worker cache version updated so the browser can load the new interface.

## First login
The administrator login is username `admin` and password `admin123`, unless you previously changed it. After logging in, change the default administrator login under **App / Admin Settings**. User Access Management and teacher registration have been removed in Version 37. The app retains only a basic local administrator login.

## Important limitations
Accounts are stored locally in this browser/device and do not synchronise to other devices. This login is an offline access barrier, not server-side security. Someone with direct access to the app source or browser storage may bypass it. Export a backup before replacing files. If records are stored in this same browser under `ca_record_v1`, they should remain in place, but always back up first.
